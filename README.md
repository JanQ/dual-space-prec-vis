# Dual-Space Preconditioning for Variational Inequalities and Root-Finding Problems
[[`arXiv`](https://arxiv.org/abs/2611.13916)]
This repository contains the code for the numerical experiments of the paper:
> [**Dual-Space Preconditioning for Variational Inequalities and Root-Finding Problems**](https://arxiv.org/abs/2611.13916)
>
> Jan Quan, Konstantinos Oikonomidis, Alexander Bodard, Panagiotis Patrinos

which has been accepted to NeurIPS 2026 as a poster.

## Experiments from the paper

The following scripts are provided in this repository:

- [aniso_coco_convergence.py](aniso_coco_convergence.py): Example 2.5, Figure 1 (left)
- [aniso_coco_convergence_not_fejer.py](aniso_coco_convergence_not_fejer.py): Example 2.6, Figure 1 (middle)
- [iso_coco_convergence.py](iso_coco_convergence.py): Example 2.8, Figure 1 (right)
- [composite_lyapunovs.py](composite_lyapunovs.py): Section 2.1
- [toilet.py](toilet.py): Example 3.5 and Figure 2
- [toy_experiments.py](toy_experiments.py): Appendix E.1, Table 2
- [wgan.py](wgan.py): Appendix E.2, Table 3
- [mnist_gan.py](mnist_gan.py): Appendix E.3, Table 4 and Figure 3
